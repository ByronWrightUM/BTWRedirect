# BTWRedirect

A dependency-free static page that redirects visitors to [Byron Wright Consulting](https://www.byronwright.com/consulting) 10 seconds after the page loads.

## Publish with GitHub Pages

1. Push this project to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing `index.html` and the `/ (root)` folder, then save.

GitHub Pages will publish the site at the URL shown in the Pages settings.
